# LearnHub

Feature-based full stack:

- `frontend/` — Next.js 15 (App Router)
- `backend/` — Express + TypeScript REST API

## Quick start

```bash
# API
cd backend
npm install
npm run dev

# Web (new terminal)
cd frontend
npm install
npm run dev
```

Open http://localhost:3000 — sign in with `admin@example.com` / `password`.
